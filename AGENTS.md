## Что это

**IVI-LiveNature** (пакет `tv.telik.ivi`) — оболочка сайта ivi.ru для приставки MXQ Pro 4K, чтобы смотреть
канал «Живая природа» (нужна подписка ivi). Стартовая страница
`https://www.ivi.ru/tvchannels/watch/zhivaya_priroda`; владелец один раз входит через «Войти» на сайте,
вход запоминается. Владелец хотел именно оболочку сайта, а не парсер.

Основной проект той же приставки — **TelikTV** (https://github.com/Dyslexia2813/TelikTV-Claude, канал
с telik.live). Там же описание приставки: `docs/DEVICE.md`.

## Приставка (коротко)

Android 7 (API 24), `armeabi-v7a`, без Google Play. Системный WebView — Chrome 52, не обновляется и не
понимает JS ivi (async-функции). ТВ 1920x1080, UI приставки 1280x720. Памяти мало.

## Устройство кода

```
app/src/main/java/tv/telik/ivi/MainActivity.java  ← GeckoView-страница, пульт→указатель, диагностика
app/src/main/java/tv/telik/ivi/NativePlayer.java  ← Media3 DASH/HLS + Widevine, полноэкранный плеер
app/src/main/assets/diag/                          ← встроенное WebExtension: bg.js, cs.js, page.js, manifest.json
app/release.keystore                               ← ключ подписи (пароль teliktv), специально в репо
```

- **GeckoView `144.+`** — последняя версия для Android 7 (145+ требует API 26). Только `armeabi-v7a`
  (`abiFilters`), APK ~86 МБ. Сборка требует AGP 8.9.1, Gradle 8.11.1, compileSdk 36, minify выключен.
- Gecko на приставке получает Widevine-ключи, но **не выводит кадры** (readyState 0). Поэтому:
  расширение `assets/diag` ловит URL манифеста и лицензии с заголовками запросов (`{t:"stream"}`),
  и `NativePlayer` играет поток сам (лицензия `https://w.ivi.ru/proxy/?content_id=...`, заголовки + куки).
  При DRM ждёт лицензию до 25 с.
- Пока играет нативный плеер, `GeckoSession` закрывается, `GeckoView` — GONE (иначе его поверхность
  закрывает картинку, и не хватает памяти); `SurfaceView.setZOrderMediaOverlay`. Назад — снова страница.
- «Живая природа» — HLS без DRM с `region-m.livecdn.ivi.ru`, есть 1080p (`avc1.4d4029`).
  Сняты ограничения по размеру экрана (`TrustingRenderersFactory` + строгий откат при ошибке декодера).

## Пульт

- Стрелки — указатель (синтетические касания/свайпы); у края экрана — прокрутка страницы или ряда постеров.
- OK — нажатие. Enter с настоящей клавиатуры уходит в страницу (формы входа).
- Назад — шаг назад по сайту; из полноэкранного видео — к странице; на первой странице — выход.
- **Вверх во время просмотра** — качество «авто» / «максимум» (pref `maxq`), значок в углу.
- Menu — диагностика; OK при открытой диагностике — переключить телефонный/компьютерный UA сайта.
- Мышь работает как обычно, правая кнопка — назад.
