# TelikIVI

Максимально лёгкая оболочка сайта ivi.ru для приставки MXQ Pro 4K (Android 7). Внутри только системный
WebView и указатель для пульта, без сторонних библиотек.

Пульт:
- стрелки двигают указатель, у края экрана прокручивают страницу или ряд постеров;
- OK — нажатие;
- Назад — шаг назад по сайту (из полноэкранного видео — выход из него), на первой странице — выход;
- Menu — строка диагностики (версии, адрес, ошибки скриптов).

Вход в аккаунт и последняя открытая страница запоминаются. Старому браузеру приставки (Chrome 52)
перед каждой страницей ivi подсовывается polyfill.js с недостающими функциями JavaScript.

APK собирается в GitHub Actions: вкладка Actions → последний запуск → артефакт `TelikIVI-apk-<версия>`.
