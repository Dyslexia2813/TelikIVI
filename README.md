# IVI-LiveNature (репозиторий TelikIVI)

Оболочка сайта ivi.ru для приставки MXQ Pro 4K (Android 7). Встроенный браузер приставки (Chrome 52) не
понимает скрипты ivi и на этой прошивке не обновляется, поэтому внутри приложения свой движок — Firefox
(GeckoView 144, последняя версия для Android 7), только для 32-битного ARM.

Сам видеопоток (с защитой Widevine) показывает встроенный плеер Android: Firefox на этой приставке получает
ключи, но не выводит кадры. Как только сайт получил поток и лицензию, страница закрывается, а видео идёт
во весь экран; Назад возвращает на страницу.

Пульт:
- стрелки двигают указатель, у края экрана прокручивают страницу или ряд постеров;
- OK — нажатие;
- Назад — шаг назад по сайту (из полноэкранного видео — выход из него), на первой странице — выход;
- Вверх во время просмотра — качество «авто» (по скорости сети) или «максимум»;
- Menu — диагностика (версии, адрес, ошибки, что умеет видеоплеер).

Мышь (USB или беспроводная) работает как обычно: клик, колесо прокрутки, правая кнопка — назад.

Вход в аккаунт запоминается. При запуске сразу открывается канал «Живая природа» (https://www.ivi.ru/tvchannels/watch/zhivaya_priroda, нужна подписка ivi: один раз войти в аккаунт кнопкой «Войти» на сайте).

APK собирается в GitHub Actions: вкладка Actions → последний запуск → артефакт `IVI-LiveNature-apk-<версия>` с файлом `IVI-LiveNature-<версия>.apk`.
