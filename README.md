# TelikIVI

Минимальное Android TV приложение для приставки MXQ Pro 4K (Android 7): только ivi.ru и канал «Живая природа».

Версия 0.1 — заготовка: открывает раздел ТВ на ivi.ru, ловит ссылку на поток (HLS/DASH) и играет её
встроенным плеером. Кнопка Menu показывает диагностику (какие запросы делает сайт, есть ли DRM).

APK собирается в GitHub Actions: вкладка Actions → последний запуск → артефакт `TelikIVI-apk-<версия>`.
